============================================================
FACE RECOGNITION PROJECT
============================================================

Пайплайн распознавания лиц, собранный «руками»:
детекция -> выравнивание -> распознавание.
В репозитории — основная часть (задания 1-3) и доп. задания 1-2.


------------------------------------------------------------
СТРУКТУРА РЕПОЗИТОРИЯ
------------------------------------------------------------

1_FaceAlignment.ipynb              (осн. задание 1)
    Подготовка датасета CelebA, Stacked Hourglass для 5 ключевых
    точек, выравнивание лиц, сборка выровненного датасета.

2_ArcFace.ipynb                    (осн. задание 2)
    Сеть-распознаватель на ResNet-50: обучение на CE и на ArcFace,
    сравнение, извлечение эмбеддингов.

3_Pipeline.ipynb                   (осн. задание 3)
    Полный пайплайн: детектор (MTCNN) -> наш Hourglass ->
    наш распознаватель; демо «один/разные люди».

1_dop_Identification_Rate_Metric.ipynb   (доп. задание 1)
    Метрика TPR@FPR (Identification Rate), все проверочные тесты
    пройдены, сравнение моделей.

2_dop_Triplet_Loss.ipynb           (доп. задание 2)
    Triplet Loss + batch-hard mining, кастомный датасет троек,
    обучение эмбеддера.


------------------------------------------------------------
ПОРЯДОК ЗАПУСКА И ЗАВИСИМОСТИ ДАННЫХ
------------------------------------------------------------

Ноутбуки связаны через общую рабочую папку (face_project на
Google Drive) и выполняются по порядку:

  1_FaceAlignment  ->  aligned/{train,val,query,distractors}/<id>/
                       (выровненные лица)
                   ->  selected_images.csv
                       (исходные имена картинок CelebA)
                   ->  hourglass_best.pt

  2_ArcFace        ->  embnet_ce.pt, embnet_arcface.pt
                       (эмбеддинг-сети)

  2_dop_Triplet    ->  embnet_triplet.pt

  3_Pipeline       <-  hourglass_best.pt + embnet_arcface.pt
                       (использует готовые веса)

  1_dop_ID_Rate    <-  embnet_*.pt + aligned/query, aligned/distractors


------------------------------------------------------------
ДАТАСЕТ
------------------------------------------------------------

- CelebA In-the-Wild (сырые фото) — скачивается отдельно.
  Критерии отбора 10 000+ изображений и обоснование — в начале
  1_FaceAlignment.ipynb.

- selected_images.csv — исходные имена отобранных картинок CelebA,
  id личности, группа (train/query/distractors) и координаты точек.
  Сдаётся вместе с проектом.

------------------------------------------------------------
КАК ЗАПУСКАТЬ
------------------------------------------------------------

1. Google Colab -> Runtime -> Change runtime type -> GPU.
2. Смонтировать Drive и поправить пути в ячейке конфигурации
   (раздел 0 каждого ноутбука): raw_images_dir, anno_dir, work_dir.
3. Выполнять ноутбуки по порядку: 1 -> 2 -> (2_dop) -> 3 -> (1_dop).

Зависимости: torch, torchvision, opencv-python,
facenet-pytorch (только для 3_Pipeline), matplotlib, pandas —
установочные команды есть в первых ячейках.


------------------------------------------------------------
ПРИМЕЧАНИЕ О ВЫВОДАХ ЯЧЕЕК
------------------------------------------------------------

Обучение требует датасета CelebA (~20 ГБ) и GPU, поэтому ячейки
обучения запускаются пользователем в Colab. Реальный вывод уже
встроен в ячейки, которые не зависят от данных/GPU и проверяют
корректность кода: формы Stacked Hourglass, sanity-check ArcFace
и Triplet loss, sanity-check выравнивания и проверочные тесты
метрики ID-Rate (все пройдены).
